# 🧠 Neural Football Predictor v5.8

Complete football prediction tool with:
- 30s gap between league fetches
- Shared localStorage
- Refresh button
- Full Manual Predict with Heatmap, Markets, Calibration
- FT History with market result boxes
- Analytics with charts and streaks
- Asian Handicap selector

## Deploy
1. Push to GitHub
2. Import in Vercel
3. Add env vars: FOOTBALL_DATA_API_KEY, API_FOOTBALL_KEY
4. Deploy
